إعداد الصفحة أول مرة (مرة واحدة فقط)

1. إنشاء مشروع Firebase
ادخل على console.firebase.google.com بحساب Google، وأنشئ مشروع جديد (مجاني بالكامل للاستخدام ده).
2. تفعيل تسجيل الدخول
من القائمة الجانبية: Build → Authentication → Get started → فعّل طريقة "Email/Password".
3. إنشاء قاعدة البيانات
من القائمة الجانبية: Build → Firestore Database → Create database (اختر أي منطقة قريبة).
4. قواعد الحماية (Rules)
في تبويب Rules داخل Firestore، الصق الكود ده واضغط Publish: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
5. إضافة مستخدمين (يوزر/باسورد لكل شخص)
من Authentication → Users → Add user، أضف بريد وكلمة مرور لكل شخص في كل قسم. كل واحد هيدخل بالبيانات دي في شاشة الدخول.
6. ربط الصفحة بالمشروع
من ⚙️ Project settings → أسفل الصفحة "Your apps" → أضف تطبيق ويب ( ) وسمّه أي اسم. انسخ الكائن firebaseConfig الظاهر، وافتح ملف الصفحة بمحرر نصوص، وابحث عن firebaseConfig في أول السكريبت واستبدله بالكائن اللي نسخته.
7. الاستضافة والمشاركة
ارفع ملف الصفحة (HTML) على أي استضافة ثابتة مجانية زي Firebase Hosting أو Netlify أو GitHub Pages، أو حتى شغّله من جهازك محليًا. بعد كده ابعت اللينك لكل الأقسام، وكل واحد يدخل ببريده وكلمة السر بتاعته.
تصدير البيانات
من تبويب (لوحة الملخص) في أي وقت اضغط "تصدير كل البيانات إلى Excel" لتحميل ملف xlsx فيه كل الشيتات والملخصات لحظيًا.
